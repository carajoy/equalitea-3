Do not reopen settled content decisions. Do not invent, rewrite, replace, or independently reinterpret locked names, roles, biography scope, program sequence, sponsor hierarchy, or design-credit treatment.

If files appear to conflict, follow this order:

2. `02_SPEAKER_ROSTER.md`
